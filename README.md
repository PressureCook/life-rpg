# Life RPG

I turned my life into an RPG.

Seven stats: Strength, Vitality, Intellect, Craft, Charisma, Creativity, Discipline. Habits and quests level them up. Ignore them and they decay, and the longer you ignore them, the faster they drop. That last rule is the whole point, because real life works like that.

One HTML file, no build step, no server. Progress saves in your browser.

**Play it:** open `index.html`, or use the hosted copy on my portfolio site.

Built for exactly one user: me. Current weakest stat: Creativity.
